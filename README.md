# README.md
Este laboratório tem como objetivo de consolidar seus conhecimentos em máquinas virtuais da Azure.
Criar uma Máquina Virtual (VM) no Microsoft Azure pelo Portal é um processo guiado e direto. O fluxo consiste em definir a infraestrutura básica, escolher o sistema operacional e o poder computacional, configurar o acesso e liberar a rede.1.Acessar e iniciar o assistente:Requer assinatura ativa do Azure.Entre no Portal do Azure (portal.azure.com), pesquise por Máquinas virtuais na barra superior e clique em Criar > Máquina virtual do Azure.2.Configurar detalhes do projeto e da instância:Na aba Básico, defina onde e o que será criado:Assinatura e Grupo de Recursos: Selecione a assinatura e crie ou escolha um Grupo de Recursos (pasta lógica para agrupar os ativos da VM).Nome e Região: Dê um nome único à VM e escolha o datacenter mais próximo dos usuários (ex.: Brazil South).Imagem e Tamanho: Escolha o sistema operacional (Windows Server, Ubuntu, Debian, etc.) e o hardware (quantidade de vCPUs e memória RAM).3.Definir conta de administrador e portas de entrada:Ainda na aba Básico, configure o acesso:Autenticação: Para Linux, prefira Chave pública SSH (mais seguro); para Windows, defina Usuário e Senha.Portas de entrada públicas: Selecione quais portas ficarão abertas na internet para acesso inicial — SSH (22) para Linux, RDP (3389) para Windows ou HTTP/HTTPS (80/443) se for um servidor web.4.Ajustar discos e rede (Opcional):Avance pelas abas Discos e Rede para personalizar o armazenamento (SSD Standard ou Premium) e a rede virtual (VNet/IP Público). Para testes rápidos, os valores padrão já funcionam bem.5.Revisar e implantar:Leva cerca de 2 a 5 minutos.Clique em Revisar + criar. O Azure validará as configurações e mostrará a estimativa de custo por hora. Após a aprovação, clique em Criar e aguarde a implantação concluir para acessar o IP público da máquina.Alternativas para automaçãoSe você precisa criar VMs de forma repetitiva ou automatizada em vez de clicar no portal, o Azure oferece ferramentas de linha de comando e infraestrutura como código:Azure CLI: Ideal para scripts rápidos no terminal (az vm create --resource-group MeuGrupo --name MinhaVM --image Ubuntu2204 --generate-ssh-keys).Azure PowerShell: Alternativa nativa para ambientes Windows (New-AzVm).Terraform / Bicep: Recomendados para ambientes de produção onde a infraestrutura precisa ser versionada em arquivos declarativos.
